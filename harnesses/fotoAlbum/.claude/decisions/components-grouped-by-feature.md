# Components grouped by feature

`src/components/` holds one component per file, in `layout/` (`Header`, `HealthMark`), `catalogue/` (`Catalogue`, `AlbumRow`, `AlbumCard`) and `making/` (`AlbumMaking`, `AlbumCharacteristics`); `test/components/` mirrors it. Where a helper that is not a component lives: [Domain folder and colocated helpers](domain-folder-and-colocated-helpers.md). Why: what changes together lives together.
