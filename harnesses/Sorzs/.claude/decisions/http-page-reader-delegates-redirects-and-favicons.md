# HttpPageReader delegates redirects and favicons

`HttpPageReader` only reads a page. `RedirectFollower` follows up to three redirects and returns an `Arrival`, which answers `isHtml` and `readFirstMegabyte` for its own response. `FaviconFinder` takes the icon `HtmlHead` declares and tries `/favicon.ico` only when none is declared; a declared icon that is not an http address is dropped without trying the root. Why: static analysis flagged the reader at cyclomatic complexity 15, from three jobs in one class and an `Arrival` record whose behavior sat in the reader (Feature Envy). Splitting brought the heaviest piece to 6.
