# Source and list entry are separate concepts

`domain/source/` holds the source (a UUID the backend generates, the address, and the title and favicon learned from the page). `domain/source-list/` holds the list and its entries (a source and the user's name). Each user's list refuses a repeated address (`registration-order-body-page-address-name`); reusing a known source for a second user waits for a store of sources apart from the list (`docs/source.md`, open questions). Name uniqueness lives in the list, and names are compared ignoring case, because the list must not show two entries that look the same. Why: the project description says the source is the same for anyone and the name belongs to the user; each has its own rules (`docs/source.md`, `docs/source-list.md`). Every entry carries its owner (`each-entry-row-carries-its-owner`).
