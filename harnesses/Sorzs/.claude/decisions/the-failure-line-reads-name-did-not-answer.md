# The failure line reads "name did not answer"

The line for a sorz in `failed` reads «<name> did not answer», in English like the other screen texts, with no cause; the frontend and the CLI use the same text. Why: the causes (network, a refusal, the 3-second cut, a wait after a 429) are not something the user can act on, and naming one would promise a precision the provider does not always have.
