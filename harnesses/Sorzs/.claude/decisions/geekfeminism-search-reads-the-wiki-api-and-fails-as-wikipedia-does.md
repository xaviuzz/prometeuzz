# Geek Feminism search reads the wiki API and fails as Wikipedia does

The provider is for one wiki. Its id is `geekfeminism`, it qualifies with `DomainQualificationStrategy("geekfeminism.fandom.com")`, and it asks `https://<hostname>/api.php` for ten results, each call cut at 3 seconds. A cut, a non-success status or an unreadable body means the sorz did not answer (`SearchFailedError`); no hits is an empty result, not a failure. Why: it is the only Fandom wiki Sorzs has a reason to search, so a provider for all of Fandom would be a rule nobody asked for, and another `fandom.com` wiki stays generic. The API is read because `Special:Search` answers 403 to a client that is not a browser. Ten results and 3 seconds follow `each-wikipedia-call-is-cut-at-three-seconds`, so no new number is invented.
