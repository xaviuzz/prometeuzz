# The CLI is a fourth repo

`Sorzs-cli`, cloned as `cli/` inside the umbrella, with its own pipeline and `CLAUDE.md`, like `backend/`, `frontend/` and `e2e/`. It supersedes the count in `umbrella-of-three-repos`; the reasons there hold. Why: the CLI has its own stack, commands and release rhythm, and each repo describes itself when opened alone.
