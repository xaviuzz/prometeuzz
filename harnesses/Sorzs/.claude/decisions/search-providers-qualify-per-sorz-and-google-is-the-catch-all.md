# Search providers qualify per sorz and Google is the catch-all

Each `SearchProvider` says whether it can satisfy a sorz entry; `SearchProviders` searches each entry with the first specialist that can, in order, else with the catch-all. `GoogleSearchProvider` is the catch-all and satisfies every entry; `SearchProvidersFactory` assembles them. Reddit qualifies by the host of the address (`reddit.com` and its subdomains), not by the path, through a `QualificationStrategy` the provider receives (`DomainQualificationStrategy`). Qualifying will not always be about the domain, so the sorz classes stay free of domain methods and each provider brings its own strategy. Why: a sorz can have a better way to be searched than a Google link, and the choice belongs to the sorz's site, not to the operation. A catch-all provider means there is never a "no provider" case to handle. The Reddit link uses the query (spaces as `+`) and is not restricted to the sorz's path: the stand-in stays honest about what the user typed. When the search moves to the frontend module, the providers and their order move with it.
