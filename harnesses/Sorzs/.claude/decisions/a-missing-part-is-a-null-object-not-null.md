# A missing part is a null object, not null

`SorzName`, `PageTitle` and `FaviconAddress` each have a `none()` form. `SorzName.fromOptional` returns it for text empty after trimming, while `SorzName.from` stays strict. A none name equals no other name, so `SorzList` and `SorzEntry` need no branch for it. `Sorz` always holds a title and a favicon; `Sorz.register` takes the address and the `PageInfo` the reader returned. Only `toJSON` turns a none into `null`. Why: a missing part is a normal state, and a null object keeps the domain free of null checks (tell, don't ask); the contract is the one place where `null` exists.
