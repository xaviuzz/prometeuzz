# Geek Feminism is its own provider with its own hint

`SearchProviderId` gains `geekfeminism`. A Geek Feminism sorz is marked in the list, the collapsed side bar and the census, with the hint "Searched by Geek Feminism"; the mark stays one icon for every specific provider. Why: shown as `generic` it would be a lie, and the census toggle "Only generic provider" would list a sorz that already has a better way to be searched. Same reasoning as `wikipedia-is-its-own-provider-with-its-own-hint`; see `a-sorz-has-a-specific-provider-or-the-generic-one`.
