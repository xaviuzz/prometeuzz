# The CLI keeps its state in one folder

The backend address (`config.json`) and the pass (`token`, mode 0600, a JSON with the token and the role) live in `~/.config/sorzs/`, or in `SORZS_HOME` when set. `SORZS_BACKEND` overrides the saved address; the default is `http://localhost:3000`. Changing the address or logging out deletes the pass; the password is never kept. Why: the token is stateless and never expires (`the-token-is-signed-and-never-expires`), so keeping it saves asking every run; it belongs to one backend, so a new address invalidates it; `SORZS_HOME` and `SORZS_BACKEND` keep tests and e2e away from the real `$HOME`. The role is kept because the pass says it (`session.md`) and a later prompt may show it; a missing or unknown role counts as user.
