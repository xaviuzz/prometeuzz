# Each face has one fixed slot

Every face has one slot of 90 % by 90 % of the page size, with 5 % of margin on the four sides, rounded inwards to the millimetre. Position and dimensions are derived from the page size and never stored; the backend keeps only the occupant of each slot, so user albums already on disk have their slots with no migration. The face number identifies the slot. Why: Xavier's choice, provisional until layouts exist; they will have to store slots and give them a code.
