# The add dialog says URL and Title and keeps an sr-only description

The fields read URL and Title. Code, contract and docs keep address and name: only the visible words changed. The description under the title is `sr-only`, not removed, so a screen reader still announces it while the screen shows only the title and the fields. Why: Xavier asked for the short labels and no visible description. "Title" in the dialog is the name the user gives the sorz, not the title of the page. A suggestion that repeats a name is refused as in `title-and-favicon-belong-to-the-sorz-the-name-stays-optional`; nothing is disambiguated automatically. Revisit if generic page titles collide often in real use.
