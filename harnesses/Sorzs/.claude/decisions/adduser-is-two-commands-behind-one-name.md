# `adduser` is two commands behind one name

`PromptAddUserCommand` (`adduser <username> [role]`, password asked without echo) and `ShellAddUserCommand` (`adduser <username> <password> [role]`) are registered under the same name, one per mode, and share `UserRegistration`, which calls the service and writes the result. Why: the two modes differ in where the password comes from and so in the line's shape and its `help` text; a single class would branch on the mode. The password is never remembered: the prompt asks it apart from the typed line, so history never holds it. In command mode it is part of the line and the shell's history holds it (accepted, see `command-mode-checks-the-role-before-calling`).
