# Domain folder and colocated helpers

`src/domain/` holds the types several parts of the app share: `album/` (`PresentedAlbum`) and `session/` (`Session`, `SessionStore`, `avatarColor`); `test/domain/` mirrors it. A helper used by one component lives beside that component (`FaceNumber` with `FaceViewer`, `rejectionReason` with `RejectedFiles`, both in `components/making/`). `src/lib/` keeps what is neither: `useReading`, shared by three, and `utils`, which shadcn generates. Why: a file lives next to its only consumer and moves up when a second one appears (`FaceNumber` goes to `domain/album/` then); a flat `lib/` mixed four unrelated kinds of file. Supersedes "What is not a component lives in `src/lib/`" in [Components grouped by feature](components-grouped-by-feature.md).
