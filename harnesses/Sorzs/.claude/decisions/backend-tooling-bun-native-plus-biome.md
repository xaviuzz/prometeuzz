# Backend tooling: Bun native plus Biome

`Bun.serve`, `bun test`, TypeScript unbuilt; Biome is the only added tool, and `he` the only runtime dependency (see `titles-are-decoded-with-the-he-library.md`). No HTTP framework and no validation library: the body is read with `Body.requireText` and `Body.optionalText`, and the rules of each value live in the domain. Why: a validation library would check the same values a second time; value objects (`SorzAddress`, `SorzName`) already carry the rules of each value, so the body is only read as text and nothing is validated twice. Revisit validation when a body carries a field `Body` cannot read, such as a number, a list or a nested object.
