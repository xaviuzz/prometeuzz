# The frontend has one provider class and composes the hint

The frontend has one `SearchProvider` class, built from `provider` and `providerName`. It answers `isSpecific()` (the id is not `generic`) and `hint()`: "Searched by {providerName}", empty when generic. The backend sends names, never screen text; the sentence lives in the frontend. A specific provider is marked in the list, the collapsed side bar and the census, with one icon for all. Why: shown as `generic` a sorz with a better way to be searched would be a lie, and the census toggle "Only generic provider" would list it. With the name in the reply a new provider needs no frontend change, and the four classes per provider and `providerNamed` disappear. The text of the hint stays in the frontend so its wording or translation never touches the backend. The census toggle reads `isSpecific()`. Companion: `the-provider-id-is-free-and-the-reply-names-it`.
