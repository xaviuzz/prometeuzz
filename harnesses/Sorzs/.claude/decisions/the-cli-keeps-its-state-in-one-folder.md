# The CLI keeps its state in one folder

The backend address (`config.json`) and the token (`token`, mode 0600) live in `~/.config/sorzs/`, or in `SORZS_HOME` when set. `SORZS_BACKEND` overrides the saved address; the default is `http://localhost:3000`. Changing the address or logging out deletes the token; the password is never kept. Why: the token is stateless and never expires (`the-token-is-signed-and-never-expires`), so keeping it saves asking every run; it belongs to one backend, so a new address invalidates it; `SORZS_HOME` and `SORZS_BACKEND` keep tests and e2e away from the real `$HOME`.
