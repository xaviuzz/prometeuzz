# Wikipedia search reads the REST search and takes its language from the sorz's address

The Wikipedia provider asks the REST search of the language site named by the sorz's address (`es` in `es.wikipedia.org`) and returns up to ten pages, each with its link and description. Why: the REST answer already carries the `key` that builds the link and the short `description`, which is all Sorzs shows; the Action API adds totals and paging that are out of scope, and moving to it stays open if they are needed. The language comes from the address and not from a setting because the user already chose it when registering the sorz, and each language is a different Wikipedia with a term that is not translated. A missing description falls back to the cleaned excerpt, so no result is empty. Findings: [wikipedia-api.md](../reference/wikipedia-api.md). Rules: `docs/wikipedia-search.md`.
