# Failed sorzs show one line each after the results

The frontend and the CLI show one line per sorz in `failed`, after all the results, in list order. The line reads «<name> did not answer», in English like the other screen texts, with no cause; both use the same text. Why: the results are what the user came for and must not move or be interleaved with failures; one line per sorz keeps each name, which a single summary banner would lose. A sorz that did not answer is not an error of the search, so it does not use the alert of a failed search. The causes (network, a refusal, the 3-second cut, a wait after a 429) are not something the user can act on, and naming one would promise a precision the provider does not always have.
