# Title and favicon belong to the source; the name stays optional

The source stores its title and favicon, learned once at first registration and never refreshed. The entry's name becomes optional; with no name the list shows the title, then the address. The title is never copied into the name by the system: not by the backend, and not when the list shows an entry. The add dialog suggests the title as the name (`a-long-title-is-shortened-only-as-a-suggestion`), and submitting it makes it the user's own choice; a suggestion left unedited that repeats a name is refused like any repeated name. Why: the name is the user's and the title is the page's (`source-and-list-entry-are-separate-concepts`); copying would make two pages with the same title collide on `SOURCE_NAME_TAKEN` without the user choosing anything. Reading once keeps the source the same for everyone and defers refresh until it is needed.
