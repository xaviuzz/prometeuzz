# Action buttons show an icon, never text

Every action button in the frontend shows only an icon. Its meaning lives in an accessible name and a tooltip: "Log out", "Backoffice", "Back to Sorzs", "Add user", "Make admin", "Make user". When no single icon says it, combine two (a user with a plus, a shield with a caret). Why: the header's buttons already work this way, and one rule keeps the toolbars and rows of later screens alike without a choice each time. Dialog buttons (Add, Cancel) are not action buttons in this sense and keep their text.
