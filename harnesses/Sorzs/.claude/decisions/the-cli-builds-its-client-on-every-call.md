# The CLI builds its client on every call

`LocatedClients` builds the generated client on every call from the current address (`BackendLocation`) and the pass in `PassStore`, and adds the `Authorization: Bearer` header only when a pass is kept. `ApiSources`, `ApiUsers`, `ApiSorzs` and `ApiHealth` take it through the `Clients` interface. `LocatedLogin` builds its own client from the address and delegates to `ApiLogin`: logging in needs no signature, and a kept pass must not travel with it. Why: `login`, `logout` and `backend <address>` change the pass and the address while the prompt is open, so a client built once at start would sign with a stale token or call a stale service. `BackendLocation.current()` is public for this reason.
