# Components grouped by feature

`src/components/` holds one component per file, in `layout/` (`Header`, `HealthMark`), `catalogue/` (`Catalogue`, `AlbumRow`, `AlbumCard`) and `making/` (`AlbumMaking`, `AlbumCharacteristics`); `test/components/` mirrors it. A component that two features share sits at the root of `src/components/`, beside the feature folders (`ReadingView`, `LoadingNotice`, `FailureNotice`, `EmptyNotice`); see [Reading states live in one ReadingView](reading-states-live-in-one-reading-view.md). Where a helper that is not a component lives: [Domain folder and colocated helpers](domain-folder-and-colocated-helpers.md). Why: what changes together lives together.
