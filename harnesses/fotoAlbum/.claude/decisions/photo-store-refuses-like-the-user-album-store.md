# Photo store refuses like the user album store

`PhotoStore.thumbnailOf` throws `PhotoNotFoundError` for a missing thumbnail, as `UserAlbumStore.find` throws its not-found error, and `ThumbnailRoute` counts it as one more refusal that answers 404. `PhotoStore.list` treats only a missing session folder as no photos; any other read failure rises to `INTERNAL_ERROR`. `PhotoStore.add` takes the `Picture`, which keeps its original bytes, so `PhotoUpload` no longer takes it apart. Why: one store answered "not there" with `undefined` and the other with an error, `list` hid real disk failures as an empty tray, and the upload had to rebuild what the picture already knew. Routes stay out of the operation registry; `Server` keeps its `if` until the transport and handler split decides how routes enter.
