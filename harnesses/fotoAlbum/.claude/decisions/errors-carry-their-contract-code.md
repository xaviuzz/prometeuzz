# Errors carry their contract code

Every error that maps to an `ErrorCode` extends `CallError` and declares its code; `Call.failureFrom` answers `error.code` and fall back to `INTERNAL_ERROR` for anything else. Why: the mapping was an `instanceof` chain copied in `CallOperation` and `PhotoUpload` (since moved to `Call.failureFrom`), and each new error meant editing both. These errors are API errors in practice, so a code on the error costs the domain nothing. The per-file refusals of an upload (`UnsupportedFormatError`, `UnreadableImageError`) keep their own enum, and `InvalidCallError` stays the transport 400.
