# Generated client: openapi-typescript and openapi-fetch

`openapi-typescript` generates only the types, `src/api/schema.d.ts`, from the pinned `openapi.yaml` with `generate`; `openapi-fetch` is the thin runtime wrapper that uses them. `generate:check` regenerates the types into a temp directory and compares them with the committed file, and CI runs it; the file is excluded from Biome. Why: the generated part is only types, and the check catches a hand-edited schema or an `openapi.yaml` copy refreshed without regenerating, with no cross-repo access. `@hey-api/openapi-ts` was rejected as heavier than the types need.
