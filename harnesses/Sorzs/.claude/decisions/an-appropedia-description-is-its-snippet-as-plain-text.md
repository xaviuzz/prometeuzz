# An Appropedia description is its snippet as plain text

The description of an Appropedia result is the `snippet` of the hit with its tags removed and its character references decoded; an empty snippet gives `""`, a valid result since `a-geekfeminism-result-has-an-empty-description`. A class `SearchExcerpt` in `infrastructure/http/` wraps an HTML excerpt and gives its plain text; Wikipedia and Appropedia both use it. Why: the snippet arrives in the same call as the hit, so a description costs no extra call, which was what ruled it out for Geek Feminism, whose snippet arrives empty. It is a fragment around the term and reads roughly, but `prop=extracts` is empty for pages that open with a list or a template and changes the reply to `query.pages[]`, so it is not used. A link to the original page with a short fragment stays inside "never answers or copied content", as the Wikipedia excerpt does. Geek Feminism keeps its empty description.
